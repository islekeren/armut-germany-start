# Bundled fonts

`OutfitVariable.ttf` is the Outfit variable font (weights 100–900), bundled so
production builds do not fetch Google Fonts or depend on Turbopack's Google font
import resolution. The app keeps the existing `--font-outfit` CSS variable.

Source: https://github.com/google/fonts/blob/main/ofl/outfit/Outfit%5Bwght%5D.ttf

Outfit is distributed under the SIL Open Font License 1.1. Its copyright notice
and full license are in `Outfit-OFL.txt`.

The existing Geist font files remain available locally.
